JobSearchOS, step by step

Eight short steps from download to your first letter. No coding. About 25 minutes the first time, most of it answering questions about yourself.

1

Download the package

Either download JobSearchOS.zip from the Releases page on GitHub and unzip it, or clone the repository. The folder you get has three parts.

2

Install it in your AI tool

Claude

Install the plugin. Either open the file JobSearchOS.plugin from the release and choose Install, or run:

/plugin marketplace add meghnesium/JobSearchOS
/plugin install jobsearchos@jobsearchos
ChatGPT or another tool

Create a Project called "Job search". Paste plugin/automations/chatgpt/project-instructions.md into its instructions. Upload the contents of plugin/skills/ and plugin/workspace-template/.

Do not have a place to put your files yet? Make an empty folder called "Job search" anywhere on your computer. You will point setup at it in step 3.
3

Run the setup

Type /setup (in ChatGPT, say "Run JobSearchOS setup"). It asks eight short blocks of questions, saves after each one, and you can stop and resume any time. Setup picks the smallest model that can do the job, to save your allowance.

Block 2 is where people rush. A pillar needs numbers with a method and a caveat. "Customers loved it" goes in the "needs a source" list and stays out of letters until you can back it.
4

See your folder

Setup builds your filing structure, including templates/ with your letter and resume in your own colours and fonts (pick them in setup, or with tools/brand-picker.html). The one thing to understand is the file name: the number at the start says where each job is, so the ones that need you rise to the top.

Say /log-application Acme, applied and the files rename themselves. A weekly check fixes any you changed by hand.

5

Write your first letter

Paste a job link and run /fast-letter. It takes two turns of your attention, nothing more.

Open the letter's HTML file in your browser and press the Export PDF button. Nothing is ever sent for you. You always send.

ChatGPT scheduled tasks cannot read Project files or write files on your computer, so the ChatGPT sweep carries your profile inside the prompt and delivers into chat. plugin/automations/chatgpt/README.md has the six steps.
8

Check what it costs

Open tools/token-budget-calculator.html in your folder. Set how many letters, intros and sweep nights you want in a week, pick a model for each phase, and see the cost and how much you save by matching the model to the job. Rule of thumb: small model for questions and search, mid model for writing, the largest model almost never.

Stuck? Re-run /setup. It resumes where you stopped and never duplicates files.
