# Pillar routing

Which pillar leads for which kind of company. Skills read this table to choose a primary and a secondary pillar. With a single pillar, routing is trivial: it always leads.

| Company size or type | Primary pillar | Secondary pillar | Tone |
|---|---|---|---|
| Under 100 people, early stage | [pillar-1-slug] | | measured-plus-one-bold |
| 100 to 500 people | [pillar-1-slug] | [pillar-2-slug] | measured-plus-one-bold |
| Over 500 people, scale or enterprise | [pillar-2-slug] | [pillar-1-slug] | measured |
| Regulated or technical domain | [pillar-slug] | | measured |
| Startup with an opinionated ad | [pillar-slug] | | bold |

## Rules

- Never borrow a number from a pillar that is not the one being used.
- The secondary pillar appears as one supporting beat, never as a second story.
- If the routed pillar has `status: draft` or `do-not-use-yet`, say so on the Decision Card and use the next ready one.
